# Build Zambia

**The 10•10•5•3•3•1•1•1 Challenge** — eight national development missions. One Zambia.

A mobile-first, offline-capable educational game (Progressive Web App) in which
players complete eight missions — Maize, Power, Tourism, Copper, Soya, Beef,
Sugar and Wheat — to build their own Zambia.

Owned by **Three Hills Zambia Ltd**. Work happens on the `preview` branch;
nothing merges to `main` without approval.
